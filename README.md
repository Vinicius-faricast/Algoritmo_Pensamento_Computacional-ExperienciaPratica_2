# Algoritmo e Pensamento Computacional - Experiência Prática 3

Estudo de vetores (arrays) aplicado ao cálculo de consumo diário de almoços ao longo de uma semana.

## Características

- Vetor `consumoDeAlmocoDiario[7]` armazena os valores de almoços consumidos em cada dia.
- Vetor `diasDaSemana[7]` guarda os nomes dos dias (strings).
- Validação de entrada positiva e tratamento de erros no `scanf`.
- Cálculo do total e da média diretamente sobre o vetor.

## Como executar

Compile e execute no terminal:

```bash
gcc Algoritmo_consumo_almoco.c -o Algoritmo_consumo_almoco
./Algoritmo_consumo_almoco
```

## Sobre o desafio

Este repositório faz parte de um desafio acadêmico que aborda o estudo de vetores, utilizando arrays em C para armazenar e processar dados relacionados ao consumo diário de almoços ao longo de uma semana.
